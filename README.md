# ULTRA FIT
PWA de musculação com treinos editáveis, biblioteca de exercícios, demonstração por vídeo online, cronômetro, histórico, evolução e backup local.

## Como usar
1. Publique esta pasta em qualquer hospedagem estática HTTPS (ex.: GitHub Pages, Cloudflare Pages ou Netlify).
2. Abra o endereço no celular.
3. Use "Adicionar à Tela de Início" para instalar como PWA.
4. Os dados básicos ficam no armazenamento local do dispositivo.

## Vídeos
A versão usa o player de busca do YouTube com consultas específicas por exercício e também oferece o botão "Abrir vídeos no YouTube". Isso evita URLs inventadas/quebradas. Os vídeos exigem internet; o restante do app e os dados já salvos continuam disponíveis offline.
